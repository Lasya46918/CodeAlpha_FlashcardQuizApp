# CodeAlpha Flashcard Quiz App

## 📚 Project Overview

The Flashcard Quiz App is a simple and user-friendly Python desktop application developed as part of the CodeAlpha App Development Internship.

The application helps users study using flashcards. Each flashcard contains a question and an answer. Users can navigate between flashcards and reveal the answer when needed.

## ✨ Features

- Display flashcard questions
- Show and hide answers
- Navigate using Next and Previous buttons
- Add new flashcards
- Edit existing flashcards
- Delete flashcards
- Store flashcards locally
- Simple and clean graphical user interface
- Resizable application window

## 🛠️ Technologies Used

- Python
- Tkinter
- JSON
- Object-Oriented Programming
